# ТУТ эээ кароче девопс туда сюда

Моя хранилка мусора. Здесь я буду занимается всякими приколами с git, CI/CD и докером XD

## Что внутри 

| Папка/Файл | Назначение |
|------------|------------|
| 'scripts/' | bash-скрипты для автоматизации |
| 'Makefile" | Удобные команды для запуска | 
| '.gitignore' | Файлы, которые git игнорирует |
| 'tests/' | Тесты для скриптов (ну пока только папка создана) |
| '.github/workflows/' | CI/CD пайплайны (их тоже пока нет) |

## Если хотите потестить или порофлить
## Клонируем репозиторий
```bash
git clone https://github.com/jonoton229/my-first-devops
cd my-first-devops
```


# Посмотреть доступные команды 
```
make help 
```

# Запустить деплой
```
make deploy
```

# Запустить деплой в production
```
make deploy-prod
```
